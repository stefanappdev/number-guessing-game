
nodeJS CLI-based number guessing game written in Typescript


HOW THIS GAME WORKS

1. To start the game enter npm run StartGame in the terminal, once executed a guide explaining the rules will appear

2. Before each round begins you will prompted to choose the difficulty level for the round

3. At the end of each round, you will be prompted to continue or exit the program.

4. To start the game cd into number-guessing-game directory and run command npm run startGame 

Roadmap.sh project URL: https://roadmap.sh/projects/number-guessing-game


Have fun and Good luck!
